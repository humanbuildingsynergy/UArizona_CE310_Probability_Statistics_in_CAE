# Contributing

Contributions from other engineering statistics educators are welcome.

## What we're looking for

- Bug reports: incorrect expected values, broken notebook cells, dataset issues
- Lab improvements: clearer prompts, better scaffolding, accessibility fixes
- New datasets: public-domain building energy or infrastructure data
- Adaptations: variations of labs for different building types or climate zones

## A note on file layout

The numbered module folders are generated from a private instructor repository,
so a pull request that renames or moves files will be overwritten on the next
build. Changes to the content of a file are what carry across — open an issue
first if you think the structure itself should change.

Most materials are published as PDF. If you want to adapt a document rather than
use it as-is, open an issue and ask for the Markdown or Marp source.

## How to contribute

1. Fork the repo and create a branch from `main`
2. Make your changes
3. Open a pull request with a short description of what changed and why

## What not to submit

Please do not submit answer keys, grader scripts, or written rubrics — these
are maintained in a separate private instructor repository.

## Contact

Open an issue for questions or suggestions.
